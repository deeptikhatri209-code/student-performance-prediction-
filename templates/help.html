Help & User Guide

Student Performance Prediction System

This system helps teachers and administrators manage student records and predict student performance based on academic information.

Features

  • Add new student records.
  • Edit existing student details.
  • Delete student records.
  • Search students quickly.
  • Predict student performance using Machine Learning.
  • Store data securely in MySQL.

How to Use

  • Go to Student Records to view all students.
  • Click Add Student to insert a new record.
  • Use the Edit button to update student details.
  • Use the Delete button to remove a student.
  • Open the Prediction page and enter student details to predict the final grade.

Prediction Inputs

  • Attendance (%)
  • Study Hours
  • Assignment Marks
  • Previous Marks

Need Assistance?

If you experience any issues while using the system, please contact the project administrator or your instructor.
